Section 4.6: Stochastic Network Formulations, Agent Heterogeneity, and Finite-Population Noise

To bridge the gap between deterministic fluid limits and production multi-agent clusters, the homogeneous mean-field model must be expanded. Real-world swarms exhibit extreme structural heterogeneity (orchestrator hubs versus sandboxed workers) and operate in small finite-population regimes (\(N\le 1000\)) where continuous-time differential averages erase critical sample-path variations.

4.6.1 Heterogeneous Graph Formulation

We relax the uniform mean-field assumptions by defining a localized interaction network via an adjacency matrix \(\mathbf{A}\in\{0,1\}^{N\times N}\), where \(A_{ij}=1\) if agent \(v_i\) can directly pass messages or invoke tools on agent \(v_j\).

Uniform scalars are replaced by node- and edge-specific quantities:

\(\mathbf{T}\in[0,1]^{N\times N}\): edge-specific trust matrix,
\(\vec{\alpha}\in\mathbb{R}_+^N\): vector of individual payload capacities,
\(\vec{\gamma}\in[0,1]^N\): per-node ingress verification efficiency,
\(\vec{\delta}\in\mathbb{R}_+^N\): per-node quarantine rates.

The instantaneous transmission rate on a directed edge is the non-homogeneous mapping
\[
\beta_{ij}(t)=A_{ij}(t)\cdot T_{ij}(t)\cdot\alpha_i(t)\cdot\bigl(1-\gamma_j(t)\bigr).
\]

4.6.2 Discrete-Event Markov Jump Process

In a finite population the state of the network is the integer vector \(\vec{X}(t)=(S(t),I(t),M(t))\) with \(S+I+M=N\). Dynamics are a continuous-time Markov chain driven by two competing propensities:

Infection event (\(\mathcal{S}\to\mathcal{I}\))  
   \[
   a_1(\vec{X})=\sum_{j\in\mathcal{S}}\sum_{i\in\mathcal{I}}\beta_{ij}(t).
   \]
   A firing produces the jump \(\vec{X}\mapsto(S-1,I+1,M)\).

Quarantine event (\(\mathcal{I}\to\mathcal{M}\))  
   \[
   a_2(\vec{X})=\sum_{i\in\mathcal{I}}\delta_i(t).
   \]
   A firing produces the jump \(\vec{X}\mapsto(S,I-1,M+1)\).

4.6.4 Stochastic Variance and Hub-Infection Volatility

Under the heterogeneous stochastic regime two phenomena invisible to the continuous ODE appear:

Bimodal outbreak variance.**  
  Sample paths bifurcate: either the seed infection remains confined to a low-degree worker and is rapidly quenched by local monitoring, or a single successful edge transmission reaches the master orchestrator.

Hub-amplification super-jump.**  
  When Node 0 enters the infected compartment its degree-\(N\) connectivity produces an instantaneous, near-linear spike in the global infection propensity. The resulting trajectory exhibits a discontinuous step-function leap that can drive the entire finite population into the infected state within a few events—even when the average parameters would have placed the corresponding mean-field system below the epidemic threshold.

These results demonstrate that accounting for structural heterogeneity and finite-population noise is an absolute architectural prerequisite. Any safety regime that relies solely on global averages or perimeter filters remains exposed to a single stochastic hop into a high-centrality hub.

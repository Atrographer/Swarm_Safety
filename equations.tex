## Network Topography & State Transitions
The system is modeled as a directed graph $G = (V, E)$, where $V$ represents the set of autonomous agent nodes ($v_i$) and $E$ represents active communication and tool-use channels.
Nodes traverse a discrete-time or continuous-time Susceptible-Infected-Mitigated ($\mathcal{S}\mathcal{I}\mathcal{M}$) compartmental loop.

* Independent-Cascade Edge Transmission Probability:
The probability that an actively infected node $v_i$ successfully compromises an adjacent secure node $v_j$ at the next operational step:
$$P(v_j \in \mathcal{I}_{t+1} \mid v_i \in \mathcal{I}_t) = T_{ij} \cdot \alpha_i \cdot \prod_{k \in \Phi_j} (1 - \gamma_k)$$ 
Where $T_{ij}$ is the implicit trust coefficient of the directed edge, $\alpha_i$ is the attack payload magnitude, $\Phi_j$ is the set of ingress verification gates for node $v_j$, and $\gamma_k$ is the empirical damping efficiency of gate $k$.
* Cumulative Global Node Activation Pressure:
The independent complement-product probability that a secure node $v_j$ is compromised given the set of all infected incoming neighbors $N^{inf}_j(t)$ at time $t$:
$$P(v_j \in \mathcal{I}_{t+1} \mid v_j \in \mathcal{S}_t) = 1 - \prod_{i \in N^{inf}_j(t)} \left( 1 - \left[ T_{ij} \cdot \alpha_i \cdot \prod_{k \in \Phi_j} (1 - \gamma_k) \right] \right)$$ 
* Automated Anomaly Quarantine Rate:
The probability per unit of time that an infected node is detected and isolated ($\mathcal{I} \to \mathcal{M}$) by telemetry monitors:
$$P(v_i \in \mathcal{M}_{t+1} \mid v_i \in \mathcal{I}_t) = \delta$$

## Mean-Field Approximations & Epidemic Thresholds
Under a standard configuration-model branching-process assumption across a sparse network graph, the global parameters are simplified to their mean-field expectations: $\langle k \rangle$ (average node degree), $\langle T \rangle$ (mean global trust), $\bar{\alpha}$ (average payload magnitude), and $\langle 1 - \gamma \rangle$ (average geometric gate omission rate).

* Effective Population Transmission Rate ($\beta$):
$$\beta = \langle k \rangle \cdot \langle T \rangle \cdot \bar{\alpha} \cdot \langle 1 - \gamma \rangle$$ 
* Basic Reproduction Number ($R_0$):
The continuous-time ratio determining whether an isolated exploit triggers a macroscopic cascade ($R_0 > 1$) or decays exponentially ($R_0 < 1$):
$$R_0 = \frac{\beta}{\delta} = \frac{\langle k \rangle \cdot \langle T \rangle \cdot \bar{\alpha} \cdot \langle 1 - \gamma \rangle}{\delta}$$ 
* Critical Trust Threshold ($\langle T \rangle_c$):
The precise topological boundary condition. If system architects enforce structural controls such that $\langle T \rangle < \langle T \rangle_c$, a systemic outbreak is mathematically impossible:
$$\langle T \rangle_c = \frac{\delta}{\langle k \rangle \cdot \bar{\alpha} \cdot \langle 1 - \gamma \rangle}$$

## Continuous-Time Deterministic Core (RK4 Equations)
To evaluate macroscopic population dynamics, the stochastic network graph is translated into a deterministic system of non-linear ordinary differential equations (ODEs), preserving conservation of mass ($N = S + I + M$).

* System of Differential Equations:
$$\frac{dS}{dt} = -\frac{\beta S I}{N}$$ 
$$\frac{dI}{dt} = \frac{\beta S I}{N} - \delta I$$ 
$$\frac{dM}{dt} = \delta I$$ 

------------------------------
## Macro-Scale Steady States

* Deterministic Endemic Equilibrium ($I^*$):
For a supercritical network configuration ($R_0 > 1$), this state equation dictates the persistent level of active infections sustained by unverified shared ambient memory pools ($\gamma \to 0$), tracking the system's final saturation threshold:
$$I^* = N \left(1 - \frac{1}{R_0}\right)$$ 

------------------------------
## Production Hardening Constraints

* Mandated Security Design Rule:
The structural safety ceiling enforced on engineering teams to absorb the risks of real-world topological anomalies, agent heterogeneity, and cooperative adversarial prompt injections:
$$R_0 \le 0.5$$
